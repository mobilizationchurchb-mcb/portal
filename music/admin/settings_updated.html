Image Reset Information
Reset Default restores the built-in church logo for the logo section. For the other three sections, it restores the default online image source. Uploaded images are stored in your Supabase Storage bucket named system-assets.

Register Administrator Account

Create an administrator account for authorized system management. The username is generated from the nickname, and a temporary password is automatically created.

Save the generated username and password securely. The password is stored as a salted PBKDF2 hash, not plain text.

Data Reset & Delete All Data

Permanently delete all devotional records, music lineups, monthly schedules, certificate requests, and issued certificate records. Church settings and administrator accounts are preserved.

Warning: Permanent Action Deleting data cannot be undone. Export or back up important records before continuing. This operation does not delete app_settings, admin_accounts, or Supabase Storage files. Participant completion saved only in an individual visitor browser is not centrally stored and cannot be cleared from this admin page.
