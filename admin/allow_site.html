Allow Users to Access the Site

This page lets the Admin Church Staff give selected members access to specific areas of the church portal. Each allowed user receives a unique PIN tied to their assigned role — Program (prog) or Praise and Worship (p&w).

Use the Generate PIN button to quickly create a secure identifier, then save the access entry. Allowed users can then use their PIN to sign in to the portal from the main login page. You can edit or revoke access at any time.
